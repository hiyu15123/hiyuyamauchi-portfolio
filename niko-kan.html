ニコニコ観光株式会社

サイトURL

https://niko-kan.co.jp/

作品概要

1960年創業、広島・福山と大阪・関西の二拠点で貸切バス・タクシーを運行するニコニコ観光株式会社のコーポレートサイトです。前職の制作会社で制作した、実際のお客様のサイトです（掲載許可取得済み）。

担当範囲

ディレクション、デザイン、実装（WordPress、Kintone・Instagram連携）、タクシー車内の写真撮影

アピール・こだわり

ディレクションからデザイン、実装まで一貫して担当しました。サイト全体の設計は自分で組み立て、コードの実装はClaude Codeを活用して進めています。WordPressで構築し、Kintoneとのデータ連携をAPIで実装したほか、公式Instagramの投稿もサイトに連携しています。お問い合わせフォームはContact Form 7で要件に合わせて作成し、可変式にしています。下層ページもモジュール単位で組み、パーツを使い回せる構成にしています。

使用技術

HTML、CSS、JavaScript、WordPress、Kintone（API連携）、Instagram連携、Claude Code
