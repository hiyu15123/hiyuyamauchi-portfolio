SKILL

HTML、Scss、Pug

習熟度：応用レベル（5/5）

BEM記法とFLOCSSで設計し、命名規則とディレクトリの方針を先に決めてから実装に入ります。実務ではPugでヘッダーやフッター、繰り返し使うパーツをモジュール単位のファイルに分け、複数ページで使い回す構成を組んでいました。色や余白はCSS変数で一元管理し、マルチデバイス対応ではSassのmixinでブレイクポイントを共通化しています。

JavaScript

習熟度：中級レベル（3/5）

Vanillaを基本に記述します。Swiper・GSAPを用いたスライダーやアニメーションの実装ができます。DOM操作を中心に、タブ切り替えやドロップメニューなどのUI実装が得意です。

アクセシビリティ

習熟度：基礎レベル（2/5）

代替テキスト、見出し階層、フォーカスの可視化といった基本を理解しています。このポートフォリオでも、画像の代替テキストの見直し、見出し階層の是正、パンくずのマークアップ、prefers-reduced-motionへの対応を行いました。WCAGに沿った検証はこれからで、実務で本格的に取り組みたい領域です。

表示パフォーマンス

習熟度：基礎レベル（2/5）

画像の書き出しサイズの見直しとフォーマット変換、ファーストビュー外の遅延読み込み、Webフォントの非同期読み込みに対応できます。このポートフォリオでは、読み込む画像の合計を14.5MBから2.6MBまで削減しました。

React.js

習熟度：基礎レベル（2.5/5）

UdemyやYoutubeでコンポーネント設計や、useStateなどのフックを学習しました。propsやフックを活用して基礎的なWebアプリを作成できます。今はTypeScriptと組み合わせたり、Next.jsを詳しく学んでいる途中です。

Vue.js

習熟度：基礎レベル（2/5）

Vueの基礎を学び、練習としてTodoリストを作成しました。refやv-onなどの基礎構文を使用して、タスクの追加や削除を実装しました。さらにローカルストレージの実装や外部ライブラリを使用してタスクを並び替えられるようにしました。

WordPress

習熟度：中級レベル（3.5/5）

2社でテーマの実装とカスタマイズを担当しました。テンプレートタグやループ処理、プラグインでのカスタマイズに加え、サーバーパネルでのデータベース構築やサイト移管、リダイレクト設定まで対応できます。個人でも静的サイトのWordPress化に取り組みました。

GA4、GTM、Clarity
